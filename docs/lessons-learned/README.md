# Lessons Learned

Esta carpeta reúne las lecciones aprendidas durante el diseño, implementación y operación de la plataforma Jarvis.

Cada documento registra una experiencia real del proyecto, incluyendo:

- el problema encontrado;
- la causa raíz;
- la solución aplicada;
- el aprendizaje obtenido.

Estas lecciones sirven como referencia para evitar repetir errores y para documentar el conocimiento adquirido durante la evolución del HomeLab.
